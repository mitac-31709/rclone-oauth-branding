# rclone OAuth branding (GitHub Pages)

Static homepage + privacy policy for the personal Google Cloud OAuth client used
by rclone / restic backups.

**Live URLs** (after Pages is enabled):

- Home: https://mitac-31709.github.io/rclone-oauth-branding/
- Privacy: https://mitac-31709.github.io/rclone-oauth-branding/privacy.html

Paste those into Google Cloud Console → **Google Auth Platform → Branding**,
then set **Authorized domains** to `mitac-31709.github.io` and **Publish** the
app under Audience.
